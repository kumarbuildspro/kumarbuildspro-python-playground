# 🐍 Kumarbuildspro Python Playground

Welcome to **Kumarbuildspro Python Playground**—a beginner-friendly, interactive web platform designed to help you learn and practice Python code directly inside your web browser with **zero setup or installation required!**

---

## 🚀 Key Features

- **📚 Beginner-Friendly Lessons:** Step-by-step interactive modules covering Python fundamentals, control flows, data structures, and more.
- **💻 In-Browser Python IDE:** Powered by **Pyodide (WebAssembly)**, letting you run Python scripts instantly in real-time.
- **⚡ Smart Autocomplete:** Built-in keyword suggestions as you type to make coding easier.
- **📝 Practice Quizzes:** Interactive quizzes after each module to test your knowledge.
- **📊 Progress Dashboard:** Automatically tracks your completed lessons, quiz scores, and code runs locally in your browser.
- **🌙 Dark Mode Support:** Clean, modern interface styled with Tailwind CSS.

---

## 🛠️ Tech Stack
- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **Pyodide v0.23.4** (Python WASM Runtime)
- **FontAwesome & Google Fonts (Inter & Fira Code)**
- **Vanilla JavaScript (ES6+)**
